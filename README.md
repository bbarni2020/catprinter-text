# catprinter-text

A minimal text-focused web app inspired by [dropalltables/catprinter](https://github.com/dropalltables/catprinter).

## Features

- Paste or type text and print it from the browser.
- Import and extract text from:
  - `.txt`
  - `.pdf`
  - `.docx`
- Styling controls before printing:
  - Font family
  - Font size
  - Bold / italic / underline / uppercase
  - Text alignment
  - Line height
  - Letter spacing
  - Plain / bulleted / numbered list rendering

## Run

Open `/home/runner/work/catprinter-text/catprinter-text/index.html` in a browser.

> Note: PDF and DOCX extraction depend on browser-loaded libraries (PDF.js and Mammoth).
